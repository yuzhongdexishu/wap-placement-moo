# Supplementary tables

Each table directory contains its original `.xlsx` workbook and one UTF-8 CSV per worksheet. The CSV files retain the worksheet rows, including title and notes rows, so they can be inspected individually on GitHub. The workbooks preserve the original formatting.

| Table | Content | Expanded sheets |
| --- | --- | --- |
| [S1](S1/) | Materials and IFC mapping | S1a, S1b, S1c |
| [S2](S2/) | Optimization and evaluation settings | S2a, S2b, S2c |
| [S3](S3/) | Sensor profiles and scenario configuration | S3a, S3b, S3c, S3d |
| [S4](S4/) | Scheme performance and receiver-level data | S4a–S4g |
| [S5](S5/) | Six-LLM run records, notes, and tool inputs/outputs | Three worksheets |

The CSV exports contain stored worksheet values. None of these workbooks contain formulas.
